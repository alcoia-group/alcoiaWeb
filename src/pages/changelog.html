Release notes

2026-08-07

Site rebuilt on the v2.0 design system

Paper-and-ink palette, self-hosted Literata / Plus Jakarta Sans, and the full sitemap from the v2.0 build brief. Every performance and accuracy claim from earlier drafts has been removed pending real-participant validation. see /research.

2026-08-07

Fonts no longer fetched from Google

The extension now packages Literata and Plus Jakarta Sans instead of requesting fonts.googleapis.com. a third-party request tied to browsing activity, removed from a product whose pitch is that it doesn't make those.

2026-08-07

Accuracy figures withdrawn

Earlier documentation carried headline accuracy figures derived from synthetic data with train/test leakage. Those figures described the data generator, not reading behaviour, and have been withdrawn pending real-participant validation. Details in /research.
