What WebGazer's licence means here

  1. While WebGazer ships inside the extension package, the client can never be closed-source. The shipped extension is a combined copyleft work: the complete corresponding source must be offered to anyone who receives it, including via any extension store.
  2. AGPL-3.0 is compatible with GPLv3 under §13 of each licence. no change needed to LICENSE.
  3. The server is unaffected: it's a separate program in a separate process, communicating over a network API.
  4. AGPL's network clause does almost nothing here. the extension runs on your machine and you already have the code; nobody deploys a browser extension as a network service. It should not be cited as a deterrent in marketing or documentation.

WebGazer's official maintenance ended 24 February 2026. It still works; updates are not guaranteed. An exit path toward a permissively-licensed alternative is logged on the roadmap, not scheduled.
