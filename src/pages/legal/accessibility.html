Accessibility statement

This product is for people who find reading hard, and it's sold to accessibility buyers. A site that fails its own audit loses those deals. so this is a commitment we're checking ourselves against, not boilerplate.

Conformance target

WCAG 2.2 Level AA, minimum, across this website. The browser extension follows the same target where the browser extension platform allows it. TODO: commission a full third-party audit before claiming conformance rather than a target.

What's built in

  • Full keyboard operability, with a visible focus ring on every interactive element
  • Semantic landmarks, one <h1> per page, real <button> elements
  • prefers-reduced-motion honoured throughout, including a static fallback for the scroll-driven demo on the home page
  • Text resizes to 200% without loss of content or function
  • Meaningful alt text on informative images, alt="" on decorative ones
  • Responsive down to 360px, including the pinned demo sequence
  • The site is fully readable and navigable with JavaScript disabled
